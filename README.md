# Tigrust
A tibber power price visualization server side rendered for the tolino epos 2.
Basically a port of tigraph, the predecessor written in go.

## Plot
The plot targets the android 4 system web browser for the Tolino Epos 2.
It has a resolution of 1440 x 1920.
Unfortunately the web browser does not support a horizontal display for webpages, so the rotation has to be done with some wonky css.
